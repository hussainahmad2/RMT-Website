RMT USA WEBSITE — PROJECT STRUCTURE & SETUP REFERENCE
================================================================================
Purpose: Canonical layout for the Revive Medical Technologies (RMT) marketing site.
Use this when restoring a disrupted archive or onboarding contributors.

Package name: rmt-usa
Last documented: August 2026

================================================================================
1. PROJECT TYPE & STACK
================================================================================

Type:        Single-page React application (SPA), client-side only
Build tool:  Vite 7
Language:    TypeScript 5.9
UI:          React 19 + Tailwind CSS 4 + shadcn/ui (trimmed primitives)
Routing:     wouter
State/data:  @tanstack/react-query (minimal); static content in src/data/*.ts
Animation:   framer-motion
Forms:       native inputs + react-hook-form where needed; EmailJS for send
Icons:       lucide-react, react-icons

There is NO backend in this repo. Contact/forms are client-side.

================================================================================
2. PACKAGE MANAGER & SCRIPTS
================================================================================

Use npm (package-lock.json). .npmrc has legacy-peer-deps=true.

  npm install
  npm run dev        → Vite dev server (port 5173)
  npm run build      → tsc --noEmit && vite build → dist/
  npm run preview    → preview production build
  npm run typecheck  → TypeScript check only

Do NOT commit: node_modules/, dist/

6. ROUTING (wouter) — MUST MATCH App.tsx
================================================================================

Base: import.meta.env.BASE_URL (usually "" or "/")

  /                           → Home
  /about                      → About
  /services                   → ServicesOverview
  /services/:slug             → ServiceRoute
  /services/:slug/:subSlug    → SubServiceRoute
  /projects                   → Projects
  /testing                    → Testing
  /training                   → Training
  /insights                   → Insights
  /insights/:slug             → InsightArticle
  /gallery                    → Gallery
  /testimonials               → Testimonials
  /products                   → Products
  /pharmaceutical             → Pharmaceutical
  /careers                    → Careers
  /contact                    → Contact
  /sitemap                    → SitemapPage
  (no match)                  → NotFound

Layout shell: Navbar → <main> routes </main> → Footer
Providers: QueryClientProvider, ThemeProvider, TooltipProvider, Toaster

ServiceRoute resolves:
  src/pages/services/<slug>/index.tsx if present
  else components/services ServiceDetail

SubServiceRoute resolves:
  src/pages/services/<slug>/<subSlug>/index.tsx if present
  else components/services SubServiceDetail
